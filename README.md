# Custom apps for Tufty 2350

My personal apps for the [Pimoroni Tufty 2350](https://github.com/pimoroni/tufty2350) badge, plus a desktop simulator to develop them without flashing the badge.

## Apps

All apps live in [`apps/user/`](apps/user). Apps with their own README have more detail.

| App | What it is |
|-----|------------|
| [alma](apps/user/alma) | Real-time version of the ALMA layered model of affect (Gebhard, AAMAS'05) driving an idle character: Big Five personality, OCC emotions, PAD mood. [README](apps/user/alma/README.md) |
| [circuit](apps/user/circuit) | Loop-drawing logic puzzle (Slitherlink-style) on a printed circuit board. |
| [clock](apps/user/clock) | Clock with text, dots, nixie and seven-segment styles, NTP sync over wi-fi and daylight-saving zones. |
| [fonttest](apps/user/fonttest) | Previews every `.ppf` bitmap and `.af` vector font in `/system/assets/fonts`. |
| [mosaic](apps/user/mosaic) | Paint-by-numbers picture logic puzzle (each number counts painted squares in its 3×3 block). |
| [notes](apps/user/notes) | Leave a note on your badge ("gone to the shop, back soon"). Edit `NOTES` in the source. |
| [psychic_paper](apps/user/psychic_paper) | Doctor Who psychic paper: shows a random authority's credentials on every press. |
| [sapper](apps/user/sapper) | Minesweeper as an arcade cabinet. |
| [star_grid](apps/user/star_grid) | Star Battle-style logic puzzle. |
| [taboo](apps/user/taboo) | Pass-and-play Taboo party game. English UI, Turkish cards generated by a Mistral agent. [README](apps/user/taboo/README.md) |
| [tdf](apps/user/tdf) | Experimental Tour de France live dashboard (proof of concept). Needs a scraper proxy on your LAN, which is not included in this repo. [README](apps/user/tdf/README.md) |

The circuit, mosaic and star_grid puzzles only include grids that can be solved without guessing.

## Layout

```
apps/
  menu/      custom launcher (replaces the stock one)
  user/      my apps, shown first in the menu
  factory/   stock Pimoroni apps go here (not committed, get them from
             https://github.com/pimoroni/tufty2350/tree/main/firmware/apps)
tools/sim/   desktop simulator
main.py      boots into /system/apps/menu
```

The stock launcher only looks at `/system/apps/*`, so this repo uses its own [`menu`](apps/menu), which reads category folders. It lists `user/` apps first, then `factory/`, then any other category folder in alphabetical order. A folder only shows up as an app if it has an `icon.png`.

## Installing on the badge

Copy `apps/` to `/system/apps/` on the badge and replace `main.py` with the one here. The launcher expects to find itself at `/system/apps/menu`.

Networked apps (clock, taboo, tdf) read credentials from `/system/secrets.py`, which you can edit on the badge's USB drive:

```python
WIFI_SSID = "..."
WIFI_PASSWORD = "..."
```

For the extra keys each app needs, see its README.

## Simulator

The simulator runs the unmodified app source in a pygame window, with hot-reload (`L`) and screenshots (`P`).

```bash
python tools/sim/run.py --app apps/user/notes
```

Always pass `--app`: the default app (`snarky_sciuridae`) isn't in this repo. Flags, controls and caveats are in [tools/sim/README.md](tools/sim/README.md).
